# Ayushman HMS

A full-stack Hospital Management System built using React, Spring Boot, PostgreSQL, JWT Authentication, and Email Services.

## Live Demo

Frontend:
https://hospital-management-frontend-4qtraiwbu-ronit-bawankles-projects.vercel.app

Backend:
https://hospital-management-backend-u64d.onrender.com

---

## Features

### Authentication & Security

* JWT Authentication
* Role-Based Access Control
* Admin, Doctor, Receptionist Roles
* BCrypt Password Encryption

### Patient Management

* Add Patient
* Update Patient
* Delete Patient
* View Patient Records

### Doctor Management

* Add Doctor
* Update Doctor
* Delete Doctor
* View Doctor Details

### Appointment Management

* Schedule Appointments
* Appointment Email Notifications

### Billing

* Generate Bills
* PDF Bill Download

### Inventory Management

* Manage Medicines
* Low Inventory Email Alerts

### Dashboard

* Total Patients
* Total Doctors
* Total Appointments
* Revenue Statistics

### Reports

* Excel Export for Patient Records

---

## Tech Stack

### Frontend

* React.js
* Axios
* Bootstrap

### Backend

* Spring Boot
* Spring Security
* Spring Data JPA
* JWT

### Database

* PostgreSQL (Neon)

### Deployment

* Frontend: Vercel
* Backend: Render

### Additional Services

* Gmail SMTP
* Apache POI
* iText PDF
